# Nome + PIN e reset admin — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sostituire il link personale con un'identità "nome e cognome + PIN di 4 cifre" che sopravvive alla cancellazione dei dati del browser, e dare all'admin il reset del PIN.

**Architecture:** La chiave del documento `persone` diventa `SHA-256(nome normalizzato minuscolo + PIN)`; il resto del modello resta. Nuovo modulo puro `profilo.js` (testato con node:test). Le regole aggiungono: nome = almeno due parole, list/delete di `persone` e creazione "reset" solo admin, cancellazione turni legata al profilo ancora esistente. La pagina perde il riquadro del link personale e guadagna schermata nome+PIN ed elenco "Soci" per l'admin.

**Tech Stack:** come il piano precedente (Firebase JS SDK 12.19.0 da CDN, Firestore rules, node:test, `@firebase/rules-unit-testing`, emulatore su porta 8181 con Java 21 in `~/.local/share/jdk/jdk-21.0.12.1+1`). Web Crypto (`crypto.subtle`) in browser e Node 22.

**Spec:** `docs/superpowers/specs/2026-09-29-turni-circolo-design.md` (rev. 2)

## Global Constraints

- Testi in italiano; titolo `Circolo Arci San Liberato — Turni`.
- Nome: obbligatori nome e cognome (almeno due parole), max 60 caratteri, spazi normalizzati.
- PIN: esattamente 4 cifre.
- Avviso nella schermata di ingresso: "**Importante:** ricorda assolutamente il tuo PIN! Ti servirà per rientrare se cambi telefono o se il telefono si dimentica di te."
- Chiave profilo: `SHA-256("turni-circolo:" + nomeNormalizzato.toLowerCase() + ":" + pin)` hex.
- Codice del circolo necessario solo per iscriversi, non per rientrare.
- Segnaposto nel repo: `CAMBIAMI` (admin), `CODICE-CIRCOLO` (codice). Mai i valori veri nel repo.
- Nomi mostrati sempre con `textContent`.
- Nessun link personale (`?io=`) rimane nel codice.

## Review Focus

1. Telefono che ha perso i dati (contesto nuovo) apre la pagina senza `?circolo=` → nome + PIN → rientra con i suoi turni. (Task 3 e2e)
2. Iscritto che sbaglia il PIN dal link del circolo → conferma "Non ti abbiamo trovato…" → Annulla → nessun profilo doppione. (Task 3 e2e)
3. Dopo reset PIN: i dispositivi col vecchio PIN tornano alla schermata di ingresso e non possono più cancellare i turni del socio; il socio rientra col nuovo PIN e ritrova i turni. (Task 2 test regole, Task 3 e2e)
4. "mario rossi" vs "Mario  Rossi" → stessa persona. (Task 1 test)
5. Nome di una sola parola / PIN non di 4 cifre → messaggio chiaro, niente iscrizione. (Task 1 test, Task 2 test regole, Task 3 e2e)

```js
// Identità del socio: nome e cognome + PIN. Stesse regole del nome di firestore.rules.
export const normalizzaNome = (s) => s.trim().replace(/\s+/g, ' ');

export function nomeValido(s) {
  const n = normalizzaNome(s);
  return n.length <= 60 && /^[^ ]+( [^ ]+)+$/.test(n);
}

export const pinValido = (p) => /^[0-9]{4}$/.test(p);

// ponytail: SHA-256 semplice; con 4 cifre il PIN resta indovinabile in 10 000 tentativi (spec, "Limiti").
export async function chiave(nome, pin) {
  const dati = new TextEncoder().encode(`turni-circolo:${normalizzaNome(nome).toLowerCase()}:${pin}`);
  const hash = await crypto.subtle.digest('SHA-256', dati);
  return [...new Uint8Array(hash)].map((b) => b.toString(16).padStart(2, '0')).join('');
}
```

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    function dispositivo() {
      return get(/databases/$(database)/documents/dispositivi/$(request.auth.uid)).data;
    }
    function persona(chiave) {
      return get(/databases/$(database)/documents/persone/$(chiave)).data;
    }
    function isAdmin() {
      return exists(/databases/$(database)/documents/admin/$(request.auth.uid));
    }
    // Nome e cognome obbligatori, spazi singoli, max 60 caratteri (come profilo.js).
    function nomeValido(nome) {
      return nome is string && nome.size() <= 60 && nome.matches('^[^ ]+( [^ ]+)+$');
    }

    // Profilo: la chiave è SHA-256 di nome + PIN. Si legge solo conoscendola; l'elenco solo l'admin.
    match /persone/{chiave} {
      allow get: if request.auth != null;
      allow list, delete: if isAdmin();
      allow create: if request.auth != null
        && chiave.size() >= 20
        && nomeValido(request.resource.data.nome)
        && (
          // Iscrizione. Sostituisci CODICE-CIRCOLO SOLO nella console Firebase, mai nel repo.
          (request.resource.data.keys().hasOnly(['id', 'nome', 'codice'])
            && request.resource.data.codice == 'CODICE-CIRCOLO'
            && request.resource.data.id == request.auth.uid)
          // Reset PIN: l'admin ricrea il profilo con la nuova chiave e lo stesso id.
          || (isAdmin()
            && request.resource.data.keys().hasOnly(['id', 'nome'])
            && request.resource.data.id is string)
        );
    }

    // Collega un dispositivo (uid anonimo) a un profilo: serve la sua chiave.
    match /dispositivi/{uid} {
      allow read: if request.auth.uid == uid;
      allow create, update: if request.auth.uid == uid
        && request.resource.data.keys().hasOnly(['id', 'segreto'])
        && persona(request.resource.data.segreto).id == request.resource.data.id;
    }

    // Un documento per giorno: "create" riesce solo se il giorno è libero.
    match /turni/{data} {
      allow read: if exists(/databases/$(database)/documents/dispositivi/$(request.auth.uid));
      allow create: if data.matches('^[0-9]{4}-[0-9]{2}-[0-9]{2}$')
        && request.resource.data.keys().hasOnly(['id', 'nome'])
        && request.resource.data.id == persona(dispositivo().segreto).id
        && request.resource.data.nome == persona(dispositivo().segreto).nome;
      // Profilo ancora esistente: dopo un reset PIN il vecchio dispositivo non cancella più.
      allow delete: if isAdmin() || resource.data.id == persona(dispositivo().segreto).id;
    }

    // Sostituisci CAMBIAMI con la parola segreta SOLO nella console Firebase, mai nel repo.
    match /admin/{uid} {
      allow read: if request.auth.uid == uid;
      allow create: if request.auth.uid == uid
        && request.resource.data.keys().hasOnly(['chiave'])
        && request.resource.data.chiave == 'CAMBIAMI';
    }
  }
}
```
